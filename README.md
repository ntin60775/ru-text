# ru-text

Зеркало [talkstream/ru-text](https://github.com/talkstream/ru-text) (MIT,
© Арсений Камышев) в упаковке ZCode-плагина: навыки `ru-text` (полный корпус:
типографика, информационный стиль, редактура, UX, деловая переписка,
анти-нейрослов), `ru-check` (вычитка read-only с перечнем находок) и
`ru-score` (оценка текста 0–10).

Контент навыков здесь не редактируется — только синхронизируется с апстримом.
Правки метода — в апстрим; этот репозиторий отвечает только за упаковку и пин.

## Релиз зеркала

Версия зеркала = версия апстрима. Обновление:

1. заменить `skills/` содержимым `skills/` апстрима нового тега, `LICENSE`
   — лицензией апстрима;
2. поднять `version` в `.zcode-plugin/plugin.json`;
3. коммит → тег `vX.Y.Z`;
4. пин `ref` в `sot-zcode-marketplace/marketplace.json` → update плагина.

## Установка

Plugin Marketplace → Add → `git@github.com:ntin60775/sot-zcode-marketplace.git`
→ установить `ru-text`. Репозитории маркетплейса и зеркала публичные —
раннер клонирует их анонимно по https, SSH-адрес в команде можно заменить
на `https://github.com/ntin60775/sot-zcode-marketplace.git`.

Контент навыков — заимствование из апстрима talkstream/ru-text: при каждом
синке проходит проверку безопасности (процедура — в реестре зависимостей
маркетплейса).
